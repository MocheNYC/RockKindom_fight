# RocoFight PVP Pet Expert Notes

这份文档用于逐只精灵补充人工理解，并把这些理解转成后续 `expert-script` 的规则。每只精灵先列出现有 PVP 条目中的稳定 id、中文名、真实特性、血脉记录、携带技能和当前固定阵容归属。

填写建议：

- `核心理解`：这只精灵最重要的机制、定位或胜利方式。
- `入场条件`：什么时候应该主动切出来，例如预判状态、聚能、强化、残血收割、抗性承伤。
- `技能循环`：常规顺序和例外情况，最好写成“如果 A 则 B，否则 C”。
- `切换规则`：什么时候保留、什么时候牺牲、什么时候必须换下。
- `Expert 规则草案`：可以直接转成脚本条件的短规则。
